Self-Hosted Setup
  1. In Google Cloud ein Projekt anlegen und die Google Drive API aktivieren.
  2. Unter OAuth consent screen eine App anlegen und dich bei Bedarf als Test-User hinzufügen.
  3. Unter Credentials einen OAuth Client ID vom Typ Web application anlegen.
  4. Als Redirect-URI diese URL eintragen: {{ url_for('main.google_drive_oauth_callback', _external=True) }}
  5. Optional als JavaScript-Origin die Basis-URL deiner Instanz eintragen, z. B. {{ request.url_root.rstrip('/') }}
  6. Client-ID und Client-Secret hier speichern und danach auf Mit Google Drive verbinden klicken.
  7. Nach der Freigabe legt die App automatisch den Ordner Photo Voting Contest Backups in deinem Drive an oder nutzt den vorhandenen.
